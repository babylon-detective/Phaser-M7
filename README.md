# Mode 7 Style Demo

A simple Mode 7 style rendering demo using Phaser 3.

## Features
- Mode 7 style perspective rendering
- Controllable player square
- WASD movement
- Acceleration mechanics

## Controls
- W: Move Up
- A: Move Left
- S: Move Down
- D: Move Right
- ]: Accelerate in facing direction

## Setup
1. Clone the repository
2. Open index.html in a web browser
